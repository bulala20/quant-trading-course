# 股票量化交易入门课

一个中文优先、可复现的 A 股研究与回测起步项目。它把数据校验、双均线策略、A 股交易约束和结果导出放在一个小而透明的代码库里，适合边学习边扩展。

这是一个可以直接运行的“研究与回测”入门项目：用历史 OHLCV 数据计算双均线信号，按下一根 K 线执行，扣除手续费和滑点，并输出净值曲线、交易记录和风险指标。

> 重要：本项目只用于学习和历史回测，不构成投资建议，也不会连接券商或自动下单。历史表现不代表未来收益。真实交易还要考虑停牌、涨跌停、复权、税费、成交量、冲击成本、流动性和合规要求。

## 1. 快速运行

在 PowerShell 中执行：

```powershell
git clone https://github.com/<your-account>/quant-trading-course.git
cd quant-trading-course
python -m pip install -r requirements.txt
python -m quant_trading demo --output-dir outputs\demo
```

如果直接下载了源码压缩包，从 `cd quant-trading-course` 开始执行即可。仓库发布后，将上面的 `<your-account>` 换成实际 GitHub 用户名。

演示会生成合成日线数据，终端打印累计收益、年化收益、最大回撤、波动率、夏普比率和交易次数，并在 `outputs/demo` 下写入：

- `input_data.csv`：演示输入数据
- `equity_curve.csv`：每个交易日的均线、仓位、成本、收益和净值
- `trades.csv`：买卖记录
- `metrics.json`：可被其他程序读取的指标

使用自己的 CSV：

```powershell
python -m quant_trading backtest .\my_stock.csv --fast 20 --slow 60 --fee-rate 0.0003 --slippage-bps 2
```

CSV 至少需要以下列（大小写不敏感）：`Date, Open, High, Low, Close, Volume`。程序会自动排序、去重，并拒绝价格不合理的数据。

### A 股研究回测

`a-share` 命令针对本地 A 股日线 CSV 增加了现金、100 股一手、买卖分方向费用、最低佣金、卖出税费、过户费、T+1 日线执行、停牌和涨跌停拒单的模拟。它默认按主板 10% 涨跌停限制处理；科创板、创业板、北交所、ST 等证券必须通过参数或后续规则配置修正，不能直接使用默认值。

```powershell
python -m quant_trading a-share .\my_a_share.csv --fast 20 --slow 60 --initial-cash 100000 --output-dir outputs\a_share
```

可选列 `Suspended` 支持 `true/false` 或 `1/0`；为真时，当天的买卖信号会被拒绝并记录为 `SUSPENDED`。程序在 `equity_curve.csv` 的 `blocked_reason` 列中记录 `SUSPENDED`、`LIMIT_UP`、`LIMIT_DOWN` 或 `INSUFFICIENT_CASH`；下一交易日仍会根据目标仓位再次尝试成交。

默认费用只是研究参数，不是对任何券商或交易所规则的声明。请在回测前按你的券商、证券市场板块和数据复权口径调整 `--buy-commission-rate`、`--sell-commission-rate`、`--sell-stamp-duty-rate`、`--transfer-fee-rate`、`--min-commission`、`--slippage-bps` 和 `--price-limit-rate`。

运行测试：

```powershell
python -m unittest discover -s tests -v
```

生成一个可复现的 A 股低价观察名单（需要联网；不自动下单）：

```powershell
python .\tools\screen_a_share.py --top 15
```

筛选逻辑是主板、现价不超过 10 元、排除 ST/退市标记、最近成交额至少 5000 万元，并要求最近 3/5 个交易日为正、收盘价在 5 日和 10 日均线上方；输出只是候选观察名单，不能解释为未来两天必涨。

筛选工具读取东方财富公开网页接口，该接口不是稳定的数据服务契约，可能限流、变更或中断。请在研究记录中保存数据时间，并在持牌行情终端中复核价格。

安装后也可以使用命令：`quant-trading demo`。

## 2. 代码怎么工作

1. `data.py` 负责数据输入和质量检查。量化研究的第一步不是选指标，而是确认数据没有缺失、重复和未来信息。
2. `strategy.py` 计算短期与长期简单移动平均线（SMA）。短均线高于长均线时，策略目标仓位为 1，否则为 0。
3. `backtest.py` 把目标仓位向后移动一根 K 线执行，所以信号在当天收盘形成，最早下一交易日才持仓；换仓时扣除 `fee_rate + slippage_bps / 10000`。
4. `cli.py` 负责命令行参数和结果导出。核心逻辑没有藏在 CLI 中，方便你继续添加 RSI、动量、因子选股或组合管理。

核心收益计算可以写成：

```text
策略日收益 = 持仓比例 × 标的日收益 - 换仓比例 × (手续费率 + 滑点率)
净值_t = 初始资金 × ∏(1 + 策略日收益)
```

## 3. 课程路线：像上课一样学

建议每课先读概念，再改一小段代码，最后写下“假设、证据、风险”三句话。

### 第 1 课：股票到底是什么

股票是对公司剩余索取权的一种证券。买入股票同时承担价格风险、公司经营风险、估值变化风险和制度风险。先区分四个词：价格（市场成交结果）、价值（对未来现金流的估计）、收益（价格和分红带来的回报）、风险（结果不确定性）。

### 第 2 课：K 线和收益率

`Open/High/Low/Close/Volume` 描述一个交易周期。绝对价格通常不可比，研究时更常用简单收益率 `P_t / P_{t-1} - 1` 或对数收益率 `ln(P_t/P_{t-1})`。本项目用收盘到收盘收益，是教学近似，不代表真实成交价。

### 第 3 课：市场、订单和成本

市价单追求成交，限价单追求价格；买卖价差、佣金、印花税、滑点和市场冲击都会吞噬策略优势。回测不扣成本，结果通常不可信。本项目把手续费和滑点作为显式参数，下一步应按你所在市场的规则校准。

### 第 4 课：指标与交易规则

指标不是预测器，而是把信息压缩成规则。双均线策略的优点是简单、可解释；缺点是震荡市反复交易、趋势反转时滞后。任何策略都要写成明确的入场、持仓、退出和仓位规则。

### 第 5 课：回测与未来函数

未来函数是用当时无法知道的信息做决策，例如用当天收盘计算信号，又假设能在当天收盘前成交。本项目将信号 `shift(1)` 后执行，并在测试中锁定这一行为。还要警惕幸存者偏差、数据 snooping 和复权错误。

### 第 6 课：如何读懂绩效

累计收益回答“赚了多少”，最大回撤回答“最痛时跌了多少”，年化波动回答“路径有多颠簸”，夏普比率回答“每单位波动换来多少平均收益”。不要只盯收益率；策略是否能承受回撤、成本和容量同样重要。

### 第 7 课：样本外、交叉验证与稳健性

把数据分成训练、验证和测试区间，参数只在训练集选择。改变均线窗口、成本、起止日期和随机种子，观察结论是否稳定。参数刚好卡在某个数上，往往是过拟合信号。

### 第 8 课：从单股到组合

组合层面要处理相关性、行业暴露、单票上限、波动率目标和再平衡。等权是好的基线；风险平价、因子加权和优化模型都必须先处理估计误差。

### 第 9 课：风控与实盘工程

设定最大仓位、单日亏损阈值、最大回撤熔断、异常数据检查和人工停机开关。实盘还需要行情接入、订单状态机、幂等、日志、告警、权限和审计；它们比“再加一个指标”更重要。

### 第 10 课：研究伦理与合规

不要把回测收益承诺给别人，不要隐瞒样本选择和成本假设，不要绕过监管或券商风控。先在纸面交易和小规模模拟环境验证，再考虑是否有资格、能力和必要性进入实盘。
